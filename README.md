# fudosan-appraisal

赤羽エリアの中古戸建購入検討のための査定パイプライン。物件テキストを構造化YAMLにし、検証済み査定エンジン(simulator v1.2移植)で「売出価格 − 土地値 − 解体費 − 建物残価 − 繰延修繕」を分解し、静的サイトとして公開する。買う/見送るの判定はエンジンでは行わない(2026-08-13。人が決める判断であるため、参照水準に対する位置を事実として出すところまで)。

- 一覧: 売出価格・市場実勢中央値・乖離額・適正中央値 + 人が設定するステータス(新規/検討中/内見済/見送り)とメモ(ブラウザ保存)
- 詳細: 価格スケール / 明細 / モンテカルロ分布(seed固定) / 感度分析 / **算出根拠の全文開示** / モデル外チェックリスト / 採用した仮定一覧

## 使い方

```bash
node engine/cli.js <property-id>   # 査定サマリ(--json で全結果)
npm test                           # 不変条件スイープ + 回帰値
npm run build                      # site/dist/ に静的サイト生成
```

依存はゼロ(js-yamlはvendor/に同梱・MIT)。npm install不要、オフラインでビルド可。

## 構成

```
engine/     査定コア(pure function)・CLI・YAML入出力
properties/ 物件YAML(1物件1ファイル)
market/     エリア別基準坪単価(公示×1.15フォールバック)
site/       静的サイトビルダー・テンプレート
tests/      floor<=fair全域スイープ・lo<=mid<=hi・NaN不発生・回帰値
.github/    push契機で test→build→GitHub Pages
.claude/    Claude Code スキル(パース→確認→査定→反映)
```

## 記載ルール(publicリポジトリのため厳守)

- 書いてよいもの: 物件の**事実データ**(価格・面積・所在地・設備)と査定パラメータのみ
- 書かないもの: 指値方針・交渉メモ・個人的所感
- 物件写真・紹介文・キャッチコピーの格納禁止(著作権・媒体規約)

## 免責

本リポジトリの査定は公開データに基づく個人検討用の簡易モデルであり、不動産鑑定評価・投資助言ではない。係数は市場慣行の近似値で統計的推定ではない。サイトにはnoindexを付与している。
