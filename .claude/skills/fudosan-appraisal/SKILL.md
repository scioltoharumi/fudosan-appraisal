# fudosan-appraisal — 中古戸建査定パイプライン

## 役割分担(絶対原則)

- **Claudeの仕事はパース・要約・レビューまで**。査定の数値計算は必ず `node engine/cli.js` を実行する
- **エンジンを介さない暗算・概算での査定値提示は禁止**(検証済みコードだけが数字を出す)

## 動作フロー(物件登録)

1. **パース**: 投入されたテキストから抽出項目を拾い、`properties/{id}.yaml` を作る
   - id は `{エリア}-{媒体番号等}`(例: `akabanedai3-20268457`)
   - 抽出項目: 価格 / 所在地(エリア判定: akabane, akabane-nishi, akabanedai, akabane-kita) / 駅・徒歩分 / 土地・建物面積 / 私道負担・セットバック / 接道(幅員・方位・角地) / 築年月 / 構造・階数 / 権利形態 / 修繕・リフォーム記載 / 仲介手数料条件
   - **元の掲載URL**: 入力テキストにURLがあれば `source_url` に記録する。無ければSUUMO物件番号から `https://suumo.jp/chukoikkodate/tokyo/sc_kita/nc_{番号}/` を構成し、**実際にアクセスして200応答かつタイトルの住所が一致した場合のみ**記録する(未確認URLのでっち上げ禁止。確認できなければ空のままにする)
   - **抽出できない項目は保守的デフォルトを適用し、YAMLに `assumed: true` と根拠を必ず記録**(例: 修繕記載なし → `repair: {status: unknown_likely_none, assumed: true, cost_man: 800}`)。推測で埋めたことを隠さない。**assumedフラグなしのデフォルト値埋めは禁止**
   - 既存YAMLと同一物件(同じ媒体番号・住所)なら新規作成せず `price_history` に追記する
   - **登録前に公式ハザードマップを機械照合する**: `node crawler/geohazard.mjs "東京都北区<地区><丁目>丁目"`。
     結果を `hazard_check.official` に記録する(verdict / 標高 / 浸水深 / 周辺25点の被覆 / 限界注記)。
     掲載の法令等制限欄には洪水浸水想定が載らないため、この照合を省くと荒川低地の物件を取り込む
     (2026-08-13の志茂1・志茂3)。verdict=block は掲載条件外なので登録しない
   - **新規登録の `status` は `new`(=一覧で「新規」)**。人がまだ見ていないものを一覧で見分けられるようにするため、`considering` を初期値にしない
2. **確認**: パース結果(YAML全文と、適用した仮定の一覧)をユーザーに提示し、承認を得る
3. **査定**: `node engine/cli.js {id}` を実行し、出力サマリをそのまま表示する
   - サマリには価格の位置(参照水準に対する事実)/下値フロア/適正レンジ/乖離/含み損/次に取るべき調査アクションが含まれる。
     **買う/見送るの判定は出さない**(2026-08-13方針。判断は人が行い、検討状況は一覧ページのステータスで設定する)
4. **反映**: 承認後に `npm test` が通ることを確認して commit & push。Pages URL を提示する

## 動作フロー(成約事例の登録)

- `market/deals.csv` に追記(出典ページに実在するレコードのみ。推測での行追加は禁止) → `node engine/calibrate.js` でエリア別の成約ベース坪単価を確認 → commit(サイトはビルド時にdeals.csv/benchmarks.yamlから較正を自動再計算)
- 地区統計は `market/benchmarks.yaml` に出典URL・期間・件数つきで記録する

## YAML記載ルール(publicリポジトリ運用)

- 書いてよいもの: 物件の事実データ(価格・面積・所在地・設備)と査定パラメータ、
  および**内見メモ・所感**(`viewing_memo` に記録する)
- 書いてはいけないもの: **指値方針・交渉の手の内**のみ(見られると価格交渉で実害がある)
- **物件写真・紹介文・キャッチコピーのリポジトリ格納は禁止**(著作権・媒体規約)
- 内見メモ・所感は2026-08-13にいったん禁止したが、**2026-08-30のユーザー指示で撤廃**した。
  ユーザーが一覧ページの書き出しJSONを貼ってきた場合、status・viewing・memo とも反映してよい

## 検証

- 変更後は必ず `npm test`(floor≦fair不変条件・回帰値)を実行。落ちた状態でpushしない
- サイト確認は `npm run build` → `site/dist/index.html` をブラウザで開く
