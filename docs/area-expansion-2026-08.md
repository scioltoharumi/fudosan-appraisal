# 調査記録: 探索エリアを王子・板橋方面へ広げる場合の候補洗い出し(2026-08-13)

status: **調査のみ・未決定**。掲載条件(検索エリア)の変更は方針変更にあたるため、ユーザー判断待ち。
再現: `node crawler/area-scan.mjs`(結果は `market/area-scan.json`) / 判定式だけ引き直す場合は `--reclassify`

## 1. 何を調べたか

現状の探索範囲(赤羽西・西が丘ほか北区12地区)では、希望条件を満たす広めの戸建が
**駅徒歩20分近く**になってしまう。延床80m2でも徒歩10分のほうがよい、という前提で
「王子駅・赤羽駅・板橋駅を結ぶ三角形」まで範囲を広げられるか、
とくに**京浜東北線(王子・東十条・赤羽)徒歩10分以内**で、ハザードを避けられる丁目はどこかを洗い出した。

対象は北区の全町丁目(浮間を除く)+ 三角形の西辺・南辺に接する板橋区・豊島区の町、計128丁目。
丁目ごとに代表点±200mの5×5=25点で、洪水浸水想定(想定最大規模)・土砂災害警戒区域等・標高を
公式タイルと機械照合し、各駅への徒歩分(1分=道路80m・直線距離×迂回率1.25)を併記した。

## 2. 分かったこと(構造)

**三角形の中は京浜東北線の線路がそのまま崖線になっている。** 線の西が武蔵野台地(標高15〜25m)、
東が荒川低地(標高3〜5m)。128丁目のうち46丁目が exclude(丁目のほぼ全域が3m超の浸水想定)で、
その46丁目は線の東側にきれいに並ぶ。

つまり「京浜東北線の駅から徒歩10分」と「ハザード回避」は、**駅の西側の半円でしか同時に成立しない**。

**駅名と町名がずれている点に注意**(ここを取り違えると探索条件を誤る):

| 駅 | 同名の町丁目 | 実際に台地側にある町丁目 |
|---|---|---|
| 東十条駅 | 東十条1〜6 = **全域が低地・除外** | 中十条1〜3・上十条1〜2・十条仲原1〜2・岸町2 |
| 王子駅 | 王子1〜6 = **全域が低地・除外** | 王子本町1〜3・岸町1・滝野川1〜2 |
| 赤羽駅 | 赤羽1〜3・赤羽南 = **全域が低地・除外** | 赤羽西1〜2・赤羽台1 |

## 3. 判定の内訳(128丁目)

判定は代表点+近傍25点から機械的に付けたもの。定義は `crawler/area-scan.mjs` の `classify()`。

- **clear 34件** — 25点すべてハザードなし(0.5m未満の着色のみは clear 扱い。台地上では通常出るため)
- **caution 35件** — 0.5〜3.0mの浸水想定またはイエローゾーンが丁目内にある
- **edge 13件** — 代表点は台地上だが、丁目の縁に3m超の浸水想定またはレッドゾーンが食い込む(番地次第)
- **exclude 46件** — 丁目のほぼ全域が荒川低地の深い浸水想定。物件単位では救えない

既知の実測との整合: 赤羽台3=edge(レッドが近傍にある。CLAUDE.md記載のレッド60mと一致)/
志茂1〜5・岩淵町=exclude(2026-08-13に台帳から除外した判断を再現)/
赤羽西4=caution(標高20.6mで0.5m未満の着色のみ。これを除外理由にしないという既存方針どおり)。

## 6. 実務上の制約(広げる場合に必要な作業)

新規候補の地区は **area-config.yaml・benchmarks.yaml・house-deals.csv のいずれにも存在しない**。
現在のエンジンは赤羽4エリアの基準坪単価しか持たないため、**このままでは査定できない**。
広げる場合に必要なのは:

1. `market/benchmarks.yaml` に対象地区の成約ベンチマークを追加(出典ページに実在するレコードのみ)
2. `market/house-deals.csv` に対象地区の成約を収載(リテール比較のプール)
3. `market/area-config.yaml` に新エリアの基準坪単価を追加
4. `crawler/daily.mjs` の `DISTRICTS` に地区を追加(日次クロールの探索対象)

なお utinokati の取引データ表には **土地形状(整形/不整形)と用途地域の列がある**。
CLAUDE.md の未了事項「house-deals.csv に土地形状列を追加し retail.js を整形地プールへ切替」は、
国交省APIの承認を待たずにこの列から着手できる可能性がある(要検証)。

## 7. この調査の限界

- 照合点は丁目の代表点+±200mを100m間隔で25点。**100m未満の幅の帯状ハザードは取りこぼす**
  (赤羽西3は代表点から94mにレッドがあるが、この格子では拾えず caution 止まり)。
  掲載の「その他制限事項」・athome備考との併用は引き続き必須(CLAUDE.md の3経路ルールは変わらない)
- 徒歩分は直線距離×迂回率1.25の近似。台帳の掲載分数を±2分で再現するが、掲載値そのものではない
- 成約データは各地区の先頭50件まで。ページ送りが機械取得できないため、件数はすべて下限値
- 上中里の成約は用途地域が準工業・近隣商業に偏る。上中里1丁目(台地・標高23.7m)と
  上中里2・3丁目(低地・除外)で性格がまったく違うが、成約データは丁目を持たないため
  どちらの成約かは駅徒歩分と用途地域からの推定に留まる
